## 🎯 Core Mission & Vision

1. **Sovereign Intelligence & Zero Vendor Lock-in**:
   We believe users and teams must own their agents, prompts, files, and credentials. Maxdots supports multi-model flexibility across Google Gemini, OpenAI, Anthropic, and OpenRouter with local SQLite storage and AES-256 Keychain encryption.

2. **Real Agent Agency (Compute + Browser + Voice)**:
   AI agents should not be confined to a text box. MaxMasAI agents ("dots") have dedicated computers (E2B cloud desktops or local Docker Linux containers), an autonomous Playwright browser, and live conversational voice calling.

3. **Multi-Agent Teams & Channels**:
   Just like human organizations use Slack and Microsoft Teams, MaxMasAI pioneers collaborative multi-agent workspaces where multiple specialized dots converse in topic channels, share context, and delegate tasks to one another.

4. **Human-in-the-Loop Safety**:
   Autonomous work requires safety. We implement granular interactive approval cards for sensitive filesystem actions, bash commands, and external integrations so humans maintain oversight.

## 🚀 Flagship Project: Maxdots (M-dots)

Maxdots is MaxMasAI's primary enterprise workspace for personal AI agents:
- **3D Puffball Avatars**: Interactive Three.js character avatars with customizable poses, colors, accessories, and eye expressions.
- **Dual Voice Engines**: Bidirectional spoken calling powered by Google Gemini 2.0 Flash models alongside OpenAI Realtime over WebRTC.
- **Computer Sandboxing**: Cloud desktop virtual machines via E2B (`@e2b/desktop`) and local Docker container environments.
- **Enterprise Integrations**: Native connectivity to 100+ business tools (GitHub, Google Calendar, Gmail, Slack, Jira, Notion) via Composio Core and the Model Context Protocol (MCP).
